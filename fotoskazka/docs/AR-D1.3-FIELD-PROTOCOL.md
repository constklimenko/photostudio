# D1.3 — Протокол полевого теста «видео поверх фотографии»

Бланк для заполнения во время теста. Что и зачем проверяется — в
`docs/AR-PROTOTYPE-TEST-PLAN.md` (§1–§4). Критерий D1.3 из roadmap: хотя бы на
одной паре «SDK × телефон» видео стабильно запускается и отслеживается при
искусственном и дневном освещении; зафиксированы предельные параметры печати.

**Страница:** `https://fotoskazkaufa.ru/webar/` (на iPhone — только HTTPS-адрес
сайта, не `localhost`). **SDK:** MindAR 1.2.5. **Таргет:** `sample-photo.jpg`,
печать из `sample-photo-print.pdf`. **Видео:** `demo-video.mp4` (8 с, без звука).

## 2. Где смотреть цифры на странице

- **Время до распознавания** — от касания «Старт» до плашки `target: found ✓`
  (засечь секундомером или по времени в журнале).
- **Удержание** — плашка `удержание: N с`; после потери значение попадает
  в строку «удержания за сессию».
- **Задержка видео** — в журнале строка
  `видео запущено через N мс после targetFound`.
- Журнал открывается кнопкой «Журнал событий» внизу экрана.

Перед каждой новой серией нажимать «Стоп» → «Старт».

## 3. Основной блок (5 попыток на строку)

Попытка = навести камеру с 25–40 см, дождаться видео, подержать ≥ 5 с.
«Успех» = видео запустилось, лежит ровно на фото и держится ≥ 5 с.
