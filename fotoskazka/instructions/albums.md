Улучшение работы с фотоальбомами

Необходимо реализовать следующие изменения.

1. Автоматическая генерация Slug

Для формы создания/редактирования Album:

при вводе Title автоматически заполнять Slug;
кириллицу транслитерировать;
переводить в lowercase;
пробелы заменять на -;
удалять недопустимые символы;
если пользователь вручную изменил Slug, дальнейшая автогенерация должна прекращаться.
2. Дозагрузка фотографий

На странице редактирования Album добавить возможность загрузки новых изображений.

Требования:

использовать существующий механизм импорта;
новые файлы добавляются к существующим;
существующие фотографии не удаляются;
автоматически создаются thumbnail и все необходимые записи в БД.
3. Управление фотографиями

Для каждого изображения внутри альбома добавить действия:

Сделать обложкой альбома;
Удалить;
(если уже поддерживается) изменение порядка.

При выборе "Сделать обложкой":

обновляется albums.cover_media_id;
предыдущая обложка становится обычной фотографией.
4. Несколько альбомов у страниц и статей

Необходимо заменить связь "одна обложка" полноценной связью many-to-many.

Требуется:

создать pivot-таблицы:
page_album
post_album
добавить отношения Eloquent:
Page::albums()
Post::albums()
обратные отношения в Album.
5. Изменить формы Filament

Для Page и Post:

сохранить существующее поле Cover Image;
добавить новое поле Albums;
использовать MultiSelect или Relation Manager;
поддерживать поиск;
сохранять связь many-to-many.
6. Обратная совместимость

Все существующие страницы, статьи и альбомы должны продолжить работать после миграций без ручного вмешательства.

Перед завершением работы обновить:

database.md;
architecture.md;
changelog.md.
