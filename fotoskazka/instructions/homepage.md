# Этап 3.1. Публичный сайт — Главная страница

Перед началом работ ознакомиться с:

* roadmap.md
* architecture.md
* database.md
* changelog.md

---

## Цель этапа

Создать основу публичной части сайта.

Важно не только реализовать главную страницу, но и заложить архитектуру, которая будет использоваться всеми последующими разделами сайта:

* Главная
* Услуги
* Портфолио
* Блог
* Контакты

---

# Задачи

## 1. Создать базовый Layout

Создать единый Blade Layout.

Например:

```
resources/views/layouts/site.blade.php
```

В него вынести:

* HTML5-разметку
* title
* meta description
* favicon
* подключение Vite
* Header
* Footer
* место для контента

Использовать Blade Components там, где это упрощает поддержку.

---

## 2. Создать структуру компонентов

Создать папку компонентов публичной части.

Например:

```
resources/views/components/site/
```

Желательно разбить Header и Footer на отдельные компоненты.

---

## 3. Реализовать Header

Header должен содержать:

* логотип
* главное меню
* кнопку "Оставить заявку"

Пункты меню:

* Главная
* Услуги
* Портфолио
* Блог
* Контакты

Пока меню можно разместить в шаблоне.

---

## 4. Реализовать Footer

Footer должен содержать:

* копирайт
* телефон
* email
* ссылки на соцсети (если заданы)
* ссылку на политику конфиденциальности

Контактные данные пока допускается хранить в конфигурационном файле.

---

## 5. Создать HomeController

Создать отдельный контроллер публичной части.

Например:

```
HomeController
```

Контроллер должен получать данные из базы и передавать их в представление.

Не выполнять запросы к БД внутри Blade.

---

## 6. Создать главную страницу

Создать маршрут:

```
/
```

Создать Blade:

```
resources/views/home.blade.php
```

---

# Структура главной страницы

Главная должна состоять из следующих блоков.

---

## Hero

Пока текст можно разместить непосредственно в шаблоне.

Блок содержит:

* заголовок
* краткое описание
* кнопку "Оставить заявку"

Фоновое изображение пока допускается хранить как обычный asset.

Не использовать БД.

---

## Услуги

Источник данных:

```
services
```

Выводить:

* опубликованные
* отсортированные по sort_order

Карточка услуги:

* обложка
* название
* краткое описание
* цена "от"

---

## Избранные работы

Источник:

```
albums
```

Условия:

```
type = 'portfolio'
is_featured = true
is_published = true
```

Показывать:

* обложку
* название

---

## Отзывы

Источник:

```
testimonials
```

Выводить только опубликованные.

---

## Последние статьи

Источник:

```
posts
```

Выводить последние опубликованные статьи.

Количество:

3

Показывать:

* обложку
* заголовок
* краткое описание
* дату публикации

---

## Форма заявки

Создать форму.

Поля:

* имя
* телефон
* услуга
* комментарий

Отправка должна создавать запись в таблице inquiries.

Без отправки email.

---

# Что хранить в БД

На данном этапе данные должны полностью поступать из БД для:

* услуг;
* портфолио;
* отзывов;
* блога.

---

# Что пока НЕ хранить в БД

До появления полноценного конструктора страниц оставить в шаблонах:

* Hero
* преимущества
* меню
* footer
* контакты
* кнопки
* статические тексты

---

# Код

Использовать:

* Route Model Binding при необходимости;
* Eloquent Relationships;
* eager loading для связанных моделей;
* пагинацию там, где потребуется в дальнейшем.

Избегать N+1 запросов.

---

# Производительность

Не выполнять запросы внутри Blade.

Все выборки производить в контроллере.

Для выборок использовать минимально необходимые поля.

---

# SEO

Для главной страницы предусмотреть:

* title
* meta description

Пока допускается хранить их в шаблоне.

В дальнейшем они будут перенесены в таблицу pages.
